# 描けるかの確かめ方

## 扱うこと

mermaid の図を書いたあと、正しく描けるかをどう確かめるか

## 答え方と理由

### 0. 判断全体

なし

### 1. 読む人の描画環境と同じ版の mermaid で、実際に描いて見る

書いた図は、読む人の描画環境と同じ版の mermaid で実際に描き、目で見て確かめる。記法を読んだだけで描けると決めない。版で使える機能が変わる（凡例は 11.17.0 以降、データラベルは 11.14.0 以降）ので、版を合わせる。描画環境の版が分からないときは、確かめた版を伝える。

1. （原因）文法は通っていたが、実際に描くと、題が切れる・ラベルが重なる・凡例が出ない・幅が0になる、といった崩れが見つかった。（発生日：2026-11-21）
2. （知見）xychart の文書は、凡例を 11.17.0 以降、データラベルを 11.14.0 以降の機能としている。（出典：S1）

### 2. 文法の誤りは、図の代わりの誤りの表示で見分ける

mermaid は、文法を読めない図を、図の代わりに「Syntax error」の表示にする。ページの中の図の数と、誤りの表示が無いことを確かめる。

1. 答え方1の理由1と同じ。

### 3. ブラウザで描くときは、ローカルの HTTP で配る

確かめ用のページをブラウザで開くときは、`file://` で開かず、ローカルの HTTP サーバー（`python -m http.server` など）で配る。描き終わったら、サーバーを止める。

1. （原因）Claude デスクトップアプリの内蔵ブラウザで `file://` のページを開くと、静的な写しとして表示され、mermaid のスクリプトが動かなかった。（発生日：2026-11-21）
