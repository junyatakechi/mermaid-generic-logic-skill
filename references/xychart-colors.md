# xychart の色

## 扱うこと

xychart で系列の色を指定するとき、どう書き、1本の棒だけ色を変えるにはどうするか

## 答え方と理由

### 0. 判断全体

なし

### 1. 色は、先頭の設定の `plotColorPalette` に、系列を書いた順に並べる

色は、図の先頭の設定の `themeVariables` → `xyChart` → `plotColorPalette` に、`,` で区切って書く。棒と線を区別せず、書いた順に1つずつ色が当たる。棒を1本ずつ違う色にする構文は無い。

```
---
config:
  themeVariables:
    xyChart:
      plotColorPalette: "#e8590c, #bfbfbf, #555555"
---
```

1. （知見）xychart の文書に、パレットの色は図の要素に順に対応するとあり、例でも線と棒を混ぜた順に色が当たっている。（出典：mermaid「XY Chart」@2026-11-21）
2. （知見）棒を1本ずつ違う色にしたいという問いに、パレットの最初の色がすべての棒に当たるだけだったという報告がある。（出典：mermaid の GitHub Discussions #5491@2026-11-21）

### 2. 1本の棒だけ色を変えるときは、棒の系列を2つ重ねる

棒の系列は、同じ x の位置に重なって描かれ、後に書いた系列が上になる。1本の棒だけ色を変えるときは、1つ目の系列に色を変える棒の値だけを入れ（ほかは0）、2つ目の系列に残りの棒の値を入れる（色を変える所は0）。色を変える系列を先に書く。

```
    bar "上限に達した週" [0, 5, 0]
    bar "それ以外の週" [2, 0, 3]
```

1. （原因）値が0の棒も、軸の上に細い線として残った。色を変える系列を後に書くと、残りの棒の下に細い色の線が見えた。先に書くと、0の細い線が後の棒に隠れた。（発生日：2026-11-21）

### 3. 「全体と、そのうちの一部」は、全体の棒の上に一部の棒を重ねる

全体の棒を先に、そのうちの一部の棒を後に書くと、一部が全体の棒の下側に重なり、積み上げのように見える。3つ以上に分けた積み上げは、下から足し上げた累積の値の棒を、大きい順に書く（全体・下の2つの和・一番下）。色は、上の部分から順に、既定の1つ目・2つ目・3つ目になる。

1. 答え方2の理由1と同じ。
2. （原因）週ごとの食事の回数を3つの入手元に分けるとき、累積の値の棒を大きい順に3つ重ねたら、3段の積み上げの棒に見え、凡例も3つの入手元で出た。（発生日：2026-11-21）

### 4. データラベル（`showDataLabel`）は、文字の大きさがばらつく

`showDataLabel: true`（11.14.0 以降）で棒の値を棒の中に出せるが、文字の大きさが棒の幅と高さで変わり、棒ごとにばらつく。重ねた系列では、値が0の棒にもラベルが出る。

1. （原因）11.17.2 で重ねた棒にデータラベルを出したら、棒ごとに文字の大きさが違い、値が0の系列のラベルも出た。（発生日：2026-11-21）

### 5. Claude デスクトップアプリのファイル表示では、色の指定が効かない

Claude デスクトップアプリのファイル表示で Markdown を見ると、xychart の色の指定は反映されない。先頭の設定（`config` → `themeVariables`）でも、`%%{init: …}%%` の指示でも、`theme: base` を足しても同じ。色は、系列を書いた順に、既定の青・橙・緑が当たる。読む人がこの表示で見るときは、色を指定せず、系列を書く順で色を決める。描く前に、読む人がどこで見るかを確かめる。

1. （原因）Claude デスクトップアプリのファイル表示で、黒・青・赤を指定した3本の線が、4つの書き方のどれでも、青・橙・緑で描かれた。凡例は出ていた。（発生日：2026-11-21）

### 6. 既定の色の順をずらすときは、名前の無い値0の系列を前に置く

色を指定できず、描く順が決まっている系列（重ねる棒の、下に描く長い棒など）に、既定の順で後ろの色を当てたいときは、その前に名前の無い値0の系列（`bar [0, 0, 0]`）を置く。その系列が前の色を受け取り、値が0なので見えず、名前が無いので凡例にも出ない。

```
    bar [0, 0, 0]
    bar "遅い見込みまで" [2.0, 5.5, 8.0]
    bar "速い見込みまで" [1.5, 4.0, 6.5]
```

1. （原因）Claude デスクトップアプリのファイル表示で、重ねる棒の下の棒を2つ目の色（橙）にしたかったが、下の棒は先に書く必要があり、1つ目の色（青）になった。前に名前の無い値0の系列を置くと、下の棒が橙、上の棒が緑になり、凡例に空の系列は出なかった。（発生日：2026-11-21）
